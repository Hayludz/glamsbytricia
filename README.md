# Glams by Tricia

Marketing website for **Glams by Tricia** — makeup artistry by Patricia.
Bookings run through WhatsApp and TikTok.

The site lives in [`site/`](site/) — five static pages, one stylesheet, one
script, no build step and no dependencies. See [`site/README.md`](site/README.md)
for how to edit prices, swap photographs, and publish.

Deployed on Vercel from the `site` directory.
